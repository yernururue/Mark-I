# Frontend MVP Plan

## Goal
Build the frontend MVP for Mark-I, fulfilling the PRD and TRD requirements.

## Proposed Architecture
- Next.js (App Router)
- Firebase Auth & Firestore
- Tailwind CSS

## Scope
- F1 Authentication
- F2 User Onboarding
- F3 Telegram Linking
- F4 GitHub Integration
- F11 Dashboard
- F10 Unified Chat
- F13 Settings
